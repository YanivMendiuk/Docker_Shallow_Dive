# Docker Shallow Dive

This repository contains assignments and hands-on exercises covering essential Docker concepts, including Dockerfiles, networking, and volumes.

---

## 📁 Docker File Assignments

Located in the `Docker_File_Assignments/` directory:

- `Dockerfile_simple` – Basic Dockerfile example
- `158_docker_file` – Custom Dockerfile configuration
- `166_docker_py_server` – Python server with Docker
- `py-web-server.py` – Simple Python HTTP server script
- `Docker_alpine_nginx` – Dockerfile using Alpine Linux and NGINX
- `index.html` – HTML page served by the container
- `alpine-env/Dockerfile_alpine_dev` – Dev environment with Alpine
- `gemini_entrypoint` – Custom entrypoint script
- `.dockerignore` – Files and folders to exclude from builds
